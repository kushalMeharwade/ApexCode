## Getting Started

1. **Install** the extension from the Visual Studio Marketplace or via
   Extensions > Manage Extensions inside Visual Studio.
2. **Open the ApexCode tool window** from View > Other Windows > ApexCode
   AI Assistant.
3. **Add your API key.** Open Settings inside the tool window, pick a
   provider (OpenAI, Azure OpenAI, OpenRouter, DeepSeek, Gemini, NVIDIA, or
   Vercel), and paste in your API key and endpoint. Click "Refresh Models"
   to pull the provider's current model list.
4. **(Optional) Choose or create a persona** to shape how the assistant
   responds — e.g., "Angular Developer" or "Database Reviewer."
5. **Start chatting.** Ask ApexCode to explain code, fix a bug, or build a
   feature. For anything that touches files, it starts in Plan Mode by
   default — review the proposed plan before approving it to switch to
   Act Mode.
6. **(Optional) Connect a SQL Server database** from Settings to let the
   assistant inspect schemas and run read-only queries during debugging.
7. **Review changes** any time via the Checkpoint window — every AI-driven
   edit is diffable and revertible.
